# Scout.Web 1.0 baseline

Date: 16 October 2026. M1–M6 implemented; ready for the user's final visual acceptance and real interview use. Physical 4K display/scaling acceptance is still open. This records the delivered development baseline, not a published installer or a claim that every environment has been certified.

Scout.Web covers companies, opportunities, application attempts, contacts, timeline and next actions; immutable documents/CV submission evidence; question and STAR preparation; an explicitly approved Interview Workspace with live capture and recovery; external recording registration/private playback; manual transcript import/corrected copies; and the desktop UX overhaul.

The [cycle index](README.md) retains all milestone plans and delivery records. [M6 delivery](milestones/MILESTONE_6_DELIVERY.md) describes the approved three-column design, central dialogs, actual browser exercises, 155 passing .NET tests, 11 passing JavaScript tests and remaining verification limits. Earlier delivery records remain the source for historical migration/restore evidence and codec/storage limits.

The application stays local, single-user and manually operated. It does not send applications, record audio itself, transcribe or extract facts. Scout.Scribe has its own cycle. General manual form drafts remain temporary; only Workspace capture has browser draft recovery. Backup the entire data root as described in [operations](../../products/scout-web/OPERATIONS.md).

Next, validate the layout using the actual display/zoom settings and use Scout in real interviews. Collect observations in the [feature wishlist](../../FEATURE_WISHLIST.md); prioritize a future Web cycle from that evidence. Scribe implementation and additional scope are separate decisions.
