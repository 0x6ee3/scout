# Runtime dependencies

This local experiment includes the following separately maintained components.
Package versions and integrity hashes are recorded in `package-lock.json`.

| Component | Version | Role | License/source |
|---|---|---|---|
| Electron | 45.0.0 | Desktop runtime | [MIT and bundled third-party notices](https://github.com/electron/electron); keep the build's LICENSE and LICENSES.chromium.html. |
| Koffi | 3.3.3 | Native Windows API calls; prebuilt N-API addon | [MIT](https://github.com/Koromix/koffi); license retained with the installed package. |
| ffmpeg-static | 5.3.0 | Supplies the streaming FFmpeg executable | [GPL-3.0-or-later package and binary release information](https://github.com/eugeneware/ffmpeg-static); retain the installed license/readme and binary notices. |

FFmpeg is a separate local child process. Its build configuration and component
licenses can be inspected with `node_modules\ffmpeg-static\ffmpeg.exe -version`
and `-L`. This project is an unpublished experiment. Any future redistribution
must review the supplied binary's licensing and corresponding-source requirements.
The packager preserves runtime dependency files and the Electron license files.

Development-only dependencies include `@electron/packager` and `playwright`; they
are pruned from the portable app. No remote fonts, UI libraries or downloaded
artwork are used. Icons are generated by `scripts/icons.cjs`.
